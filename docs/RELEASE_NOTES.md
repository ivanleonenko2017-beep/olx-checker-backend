# Знайдено 1.0.0 — нотатки для тестувальників

Знайдено допомагає зберігати пошукові фільтри та отримувати сповіщення про нові оголошення, які відповідають критеріям.

## Що перевіряємо

- Створення, перегляд і видалення власних фільтрів.
- Пошук смартфонів за моделлю, містом, пам'яттю та станом.
- Окремий пошук аксесуарів.
- Сповіщення про нові оголошення без повторів.
- Профіль, тарифні обмеження, реферальний розділ та адміністративну панель.
- Відображення документів зі статусом «Чернетка».

## Важливо

- Результати залежать від доступності та розмітки OLX; сервіс не гарантує виявлення кожного оголошення.
- Render Free може засинати після простою, тому перший запит після паузи може завантажуватися довше.
- Документи є чернетками, не юридичним висновком чи затвердженою офертою.
- Реальні платежі не перевірені в цьому проході. Не надсилайте кошти під час тесту.
- Не запускайте масові розсилки.
- Якщо бачите повторні сповіщення, неправильне місто/модель або порожній результат, зафіксуйте запит і час для діагностики.

## Статус

Версія готується до обмеженого тестування. Повний публічний комерційний запуск не оголошений.
